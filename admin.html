Connect Live Auto-Publish

Because MEEM is hosted as a lightning-fast static site on Render, connecting your GitHub token once lets you publish Show/Hide/Add updates straight to meem-invitations.onrender.com for all customers in ~20 seconds.

One-Time Setup (30 seconds):
1. Open github.com/settings/personal-access-tokens/new
2. Select Only select repositories → 8ofrii/meem-invitations
3. Under Repository permissions, set Contents to Read and write.
4. Click Generate token and paste it below (saved privately in this browser only).
